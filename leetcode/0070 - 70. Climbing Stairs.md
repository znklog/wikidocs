## 문제
[https://leetcode.com/problems/climbing-stairs](https://leetcode.com/problems/climbing-stairs)

한번에 1계단씩과 2계단씩 오르는 방법이 있을 때 전체 n계단을 오르는 방법의 가짓수를 구하는 문제


## 반복문 사용 동적 계획법(dynamic programming)
```python
# 런타임 0 ms, 메모리 19.12 MB
class Solution:
    def climbStairs(self, n: int) -> int:
        a = [0] * max(3, n + 1)
        a[1], a[2] = 1, 2

        for i in range(3, n + 1):
            a[i] = a[i - 2] + a[i - 1]

        return a[n]
```

[동적 계획법](https://namu.wiki/w/%EB%8F%99%EC%A0%81%20%EA%B3%84%ED%9A%8D%EB%B2%95)을 사용하여 풀 수 있는데 초기단계의 고정값인 초기값과 n단계와 n단계 이전의 관계식인 일반항을 이용해서 풀어내는 알고리즘

`n`단계 계단 오르는 가짓수를 `f(n)`이라 하면 아래와 같이 나타낼 수 있음
```plaintext
초기값: f(1) = 1, f(2) = 2
일반항: f(n) = f(n-2) + f(n-1)
```

`2`계단일 때는 한번에 한 계단씩 오르거나 두 계단을 한번에 오르는 방법 2개가 있으며, `n`계단일 때는 `n-2`계단까지 오른 뒤 남은 두 계단을 한번에 오르는 방법과 `n-1`계단까지 오른 뒤 남은 한 계단을 오르는 방법이 있어 그 합을 구하면 됨

위 코드에서 `a`는 `n`단계의 가짓수를 담는 리스트임, 초기값은 미리 정의하고 반복문으로 `n`단계를 순차적으로 계산함


## 반복문 사용 동적 계획법 간단 방식
```python
# 런타임 0 ms, 메모리 19.19 MB
class Solution:
    def climbStairs(self, n: int) -> int:
        a, b = 1, 2

        for i in range(2, n + 1):
            a, b = b, a + b

        return a
```

최종 `n`단계의 결과만 필요하다고 하면 위와 같이 나타낼 수 있음

`a` 변수값이 계속 업데이트되는 형태임


## 재귀함수 사용 동적 계획법과 메모이제이션(memoization)
```python
# 런타임 1 ms, 메모리 19.21 MB
class Solution:
    def climbStairs(self, n: int) -> int:
        def memoize(f):
            h = {}

            def wrapper(n):
                if n not in h:
                    h[n] = f(n)

                return h[n]

            return wrapper

        @memoize
        def f(i):
            return i if i < 3 else f(i - 2) + f(i - 1)

        return f(n)
```

`f` 함수가 n단계 계단 오르는 가짓수 구하는 핵심 함수로 재귀함수를 사용한 동적 계획법으로 구현되어 있음

이 함수만 사용해서는 재귀호출로 인한 반복계산이 너무 많아 시간 초과로 풀리지 않음, 한번 계산했던 결과는 저장해뒀다가 다시 사용하는 [메모이제이션](https://namu.wiki/w/%EB%A9%94%EB%AA%A8%EC%9D%B4%EC%A0%9C%EC%9D%B4%EC%85%98) 기법이 추가되어야 함

python 데코레이터 문법으로 메모이제이션을 구현하는 `memoize` 함수가 `f` 함수를 래핑하는 형태임


## cache 데코레이터 사용
```python
# 런타임 0 ms, 메모리 19.23 MB
import functools


class Solution:
    def climbStairs(self, n: int) -> int:
        @functools.cache
        def f(i):
            return i if i < 3 else f(i - 2) + f(i - 1)

        return f(n)
```

python이 functools 모듈에서 제공하는 `cache` 데코레이터를 사용하여 메모이제이션을 구현함

자세한 내용은 [python 문서](https://docs.python.org/ko/3/library/functools.html#functools.cache) 참고할 것


## 피보나치 수열 공식 응용
```python
# 런타임 0 ms, 메모리 19.21 MB
class Solution:
    def climbStairs(self, n: int) -> int:
        a = 5**0.5
        b = (1 + a) / 2
        c = round(b ** (n + 1) / a)

        return c
```

계단 오르는 가짓수가 [피보나치 수열](https://namu.wiki/w/%ED%94%BC%EB%B3%B4%EB%82%98%EC%B9%98%20%EC%88%98%EC%97%B4)과 매우 닮아 있음

그리고 피보나치 수열은 [황금비](https://namu.wiki/w/%ED%99%A9%EA%B8%88%EB%B9%84)와 관련이 큰데, 동적 계획법 말고도 황금비를 구하는 식을 응용한 공식(비네의 공식이라고도 함)을 사용해서 풀어낼 수 있음

`c` 변수를 구할 때 `n + 1` 대신 `n`을 사용하면 본래의 n단계 피보나치 수를 구하는 공식이 됨
