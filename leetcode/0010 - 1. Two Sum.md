## 문제
[https://leetcode.com/problems/two-sum](https://leetcode.com/problems/two-sum)
정수로 이뤄진 배열 `nums`와 `target`이 주어질 때 합이 `target`이 되는 두 원소의 인덱스를 리턴하는 문제
반드시 정답이 되는 유일한 원소 쌍이 존재하며, 하나의 원소를 두 번 사용하는 케이스는 없음

## 완전 탐색(brute force)
```python
# 런타임 1623 ms, 메모리 19.64 MB
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        for i in range(len(nums) - 1):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]
```
`nums`에서 조합할 수 있는 모든 원소 쌍 케이스를 탐색하는 [완전 탐색](https://namu.wiki/w/Brute%20Force) 방식을 사용
모든 원소 쌍을 만들기 위해 이중 루프를 사용하나 반드시 모든 루프가 `nums` 처음부터 끝까지 탐색해야 하는 것은 아님
외부 루프 순회값인 `i`는 `nums` 마지막에서 두 번째 인덱스까지만 순회하면 되며 내부 루프 순회값인 `j`는 외부 루프가 가리키는 인덱스의 다음 인덱스인 `i+1`부터 탐색하면 됨

## 해시 테이블(hash table)
```python
# 런타임 1 ms, 메모리 20.38 MB
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        h = {}

        for i, x in enumerate(nums):
            y = target - x
            if y in h:
                return [h[y], i]

            h[x] = i
```
`nums`를 순회하면서 순회했던 원소값과 인덱스를 [해시 테이블](https://namu.wiki/w/%ED%95%B4%EC%8B%9C#s-4)에 기억시킴, 그리고 이후의 순회에서 원소값이 기억해 뒀던 어떤 원소값과 합이 `target`이 되었을 때 리턴하는 방식으로, 완전 탐색과 달리 한 번의 순회로 문제 풀이가 가능
해시 테이블 역할로 `h` 딕셔너리 상정, 그리고 `nums`를 인덱스 `i`와 원소값 `x`로 순회하면서 `y = target - x`를 미리 구함, 만일 `y`가 `h`에 있었다면 해당 인덱스들을 리턴하고, 아니라면 다음 순회를 위해 `h`에 `{원소값: 인덱스}` 형식으로 데이터를 저장

## 투 포인터(two pointers)
```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        nums = sorted(
            ({"idx": i, "val": x} for i, x in enumerate(nums)), key=lambda x: x["val"]
        )
        lo, hi = 0, len(nums) - 1

        while lo < hi:
            t = nums[lo]["val"] + nums[hi]["val"]
            if t < target:
                lo += 1
            elif target < t:
                hi -= 1
            else:
                return [nums[lo]["idx"], nums[hi]["idx"]]
```
`nums`를 `{"idx": 인덱스, "val": 원소값}, ...` 형식의 배열로 전환하고, `"val"` 오름차순으로 정렬시킴
`nums`의 하한과 상한 인덱스를 각각 `lo`와 `hi` 포인터가 가리키도록 한 뒤, 두 포인터가 가리키는 값의 합인 `t`와 `target`을 비교해서 `lo` 또는 `hi`를 이동시킴
