## 문제
[https://leetcode.com/problems/valid-parentheses](https://leetcode.com/problems/valid-parentheses)

소·중·대 괄호로 이뤄진 문자열 `s`가 올바른 괄호쌍으로만 이뤄진 문자열인지 체크하는 문제

올바른 괄호 쌍이 되려면, 1. 여는 괄호는 동일 타입의 닫는 괄호로 닫혀야 하고, 2. 올바른 순서로 닫아야 하고, 3. 닫는 괄호는 동일한 타입의 여는 괄호가 앞에 있어야 함


## 반복문으로 올바른 괄호 쌍 제거
```python
# 런타임 59 ms, 메모리 19.08 MB
class Solution:
    def isValid(self, s: str) -> bool:
        p = ""
        while p != s:
            p = s
            s = s.replace("()", "").replace("{}", "").replace("[]", "")

        return p == ""
```

while 반복문으로 `s` 에서 올바른 괄호 쌍을 계속 제거해 가는데 더 이상 제거가 불가능한 경우 즉 `p == s`일 때 반복문 탈출함

만일 올바른 괄호 쌍이었다면 `p` 또는 `s`는 어떠한 괄호도 남아있지 않아야 함


## 스택(stack) 사용
```python
# 런타임 1 ms, 메모리 19.16 MB
class Solution:
    def isValid(self, s: str) -> bool:
        h = {")": "(", "}": "{", "]": "["}
        st = []

        for x in s:
            if x in h:
                if not st or st.pop() != h[x]:
                    return False
            else:
                st.append(x)

        return len(st) == 0
```

[스택](https://namu.wiki/w/%EC%8A%A4%ED%83%9D(%EC%9E%90%EB%A3%8C%EA%B5%AC%EC%A1%B0))의 후입선출 특성을 활용한 방식

`st` 리스트를 스택으로 두고, 문자열을 `x`로 순회하여 여는 괄호라면 스택에 저장하고, 닫는 괄호라면 `st`에서 후입선출로 괄호를 꺼내어 동일한 타입의 여는 괄호인지를 체크해가는 방식

올바른 괄호 쌍만 있다면, `x`가 닫는 괄호일 때 `st`는 비어있지 않아야하고, 후입선출로 꺼낸 괄호가 동일한 타입의 여는 괄호이어야 하며, 순회 종료 후 `st`에는 괄호가 남아있지 않아야 함
